# 国龙外校 高二上期中考点速查（EPUB 分册）

桂林市国龙外国语学校 · 物化生选科 · 语文仅古诗文、英语仅单词 · 按**题干特征**分册，共 20 册。

## 教材版本（已核实）

广西 2024 秋起进入新高考（3+1+2），教材**按市选用、并非全区统一**。桂林市：

| 学科 | 桂林版本 |
| --- | --- |
| 语文 / 政治 / 历史 | 全国统编版（人教社） |
| 物理 / 化学 / 生物学 | 人教版(2019) |
| 英语 | **外研版(2019 新标准)** |
| 数学 | 北师大版（本套不含数学） |

对照：英语南宁、柳州等用人教版；物理钦州/贵港/来宾用教科版；化学钦州/贵港/河池用苏教版；生物梧州用浙科版。
本套资料已按桂林实际版本编写，英语三册（18–20）为外研版选必一/二/三词表。

## 用法

打开 `00_速查索引.html`，输入题目里的关键词（如「碰撞」「反射弧」「盖斯定律」「情境默写」「电极反应式」），实时筛出对应分册；文件名已简化，只保留最核心的 2–4 个锚点词。

- 物理 01–05：动量碰撞 / 振动与波 / 静电场 / 电路与实验 / 光学
- 化学 06–10：反应热 / 速率平衡 / 离子平衡 / 电化学 / 方向与调控
- 生物 11–14：内环境 / 神经 / 体液 / 免疫与植物激素
- 语文 15–17：诸子与必修文言 / 史传与唐宋古文 / 默写与文言基础
- 英语 18–20：外研选必一 / 外研选必二 / 外研选必三+词族辨析自测

## 口径

按「必修三 + 选必全册 + 进度储备」上限覆盖（国龙理科进度偏快）；只保留公式、结论、判断口径与易错点，不铺陈讲解。
依据公开教材目录与同类示范校统考范围整理，**非学校官方发布**；最终考试范围以年级组与任课教师通知为准。
