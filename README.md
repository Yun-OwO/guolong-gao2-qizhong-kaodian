# 国龙外校 高二上期中考点速查

**交付形态：单个 HTML 文件 `考点速查.html`** —— 纯本地、零外部依赖、双击即用（file:// 可用），含全文搜索 + 按题干特征分类的快速筛选（可叠加），针对 324×394 竖屏与低性能设备优化。

桂林市国龙外国语学校 · 物化生选科 · 语文仅古诗文、英语仅单词 · 共 20 类题干特征、63 条考点。

## 用法

打开 `考点速查.html`（浏览器直接打开，无需联网、无需服务器）：
- 顶部输入题目关键词，如「人船模型」「反射弧」「盖斯定律」「情境默写」「克己复礼」。
- 可先点学科、再点 **题干特征分类**（20 类）做快速筛选，筛选与搜索叠加生效。
- 点卡片展开正文；底部「全部」复位。

## 教材版本（已核实）

广西新高考教材**按市选用、并非全区统一**。桂林市：语文为全国统编版；物理、化学、生物学为**人教版(2019)**；英语为**外研版(2019 新标准)**；数学为北师大版（本套不含）。对照：英语南宁柳州等用人教版；物理钦州/贵港/来宾用教科版；化学钦州/贵港/河池用苏教版；生物梧州用浙科版。

## 技术说明

单文件内嵌全部内容、CSS 与 JS，**无任何外部请求**（无 CDN、无外部字体/图片、无 fetch）。搜索为构建期预建索引 + 运行时纯 indexOf 匹配，160ms 防抖、结果上限 40 条并分批渲染、正文点击才注入 DOM，避免低性能设备卡顿或搜索卡死；表格转为竖排键值卡，无横向滚动；点击区 ≥ 36px，适配 324×394 竖屏单手操作。

## 口径与免责

按「必修三 + 选必全册 + 进度储备」上限覆盖（国龙理科进度偏快）；只保留公式、结论、判断口径、易错点与必背句。依据公开教材目录与同类示范校统考范围整理，**非学校官方发布**；最终考试范围以年级组与任课教师通知为准。古诗文原文以课本为准。
